# Pendaftaran Lomba 17-an RT 04 🇮🇩

Aplikasi web Pendaftaran Lomba 17 Agustus 1945 untuk warga **Perum. Sukamaju Permai RT 04 / RW 12, Cilodong, Kota Depok**.

Aplikasi ini dibangun menggunakan **React.js (Vite)** dan terintegrasi langsung dengan **Google Sheets** menggunakan **Google Apps Script (GAS)** tanpa memerlukan server backend berbayar.

## ✨ Fitur Utama
* 📱 **Tampilan Responsive & Modern**: Desain tematik Merah-Putih HUT RI Ke-81 yang nyaman diakses dari Smartphone dan Laptop.
* 👨‍👩‍👧‍👦 **Pendaftaran Multi-Peserta**: Mendaftarkan lebih dari 1 peserta (Anak, Bapak, maupun Ibu) dalam 1 kali pengisian formulir.
* 📊 **Google Sheets Live Integration**: Data pendaftaran terkirim secara *real-time* ke spreadsheet panitia Karang Taruna.
* 📲 **Struk Digital & Direct WhatsApp**: Menampilkan bukti pendaftaran digital dan tombol konfirmasi otomatis ke WhatsApp Panitia (`0895705290500`).

## 🚀 Cara Menjalankan Proyek
1. Clone repositori ini:
   ```bash
   git clone https://github.com/Shodiqwae/Form-Pendafataran-17-.git
   cd Form-Pendafataran-17-
   ```
2. Install dependensi:
   ```bash
   npm install
   ```
3. Jalankan server lokal:
   ```bash
   npm run dev
   ```
